  <action>
    **FeedbackFilter** (src/dsp/FeedbackFilter.h):
    Header-only, JUCE-free class. Two one-pole audio filters (HP and LP) with per-channel state (dual mono, max 2 channels).

    LP: `y[n] = y[n-1] + alpha * (x[n] - y[n-1])` where `alpha = 1 - exp(-2*pi*fc/sr)`
    HP: Use subtraction method: `hp_out = input - lowpass(input)` with a separate LP state for the HP path. This avoids the DC drift issues of the direct HP difference equation.

    Each filter has a bypass bool. When bypassed, skip processing entirely (don't update state). Default: both bypassed. Coefficients updated when setLPFrequency/setHPFrequency called. Signal chain: HP first, then LP (per CONTEXT.md: filters before saturation; within filters, HP before LP removes low-end before LP smooths).

    Add denormal protection: `if (std::abs(state) < 1e-15f) state = 0.0f;` after each state update.

    **FeedbackSaturator** (src/dsp/FeedbackSaturator.h):
    Header-only, JUCE-free class. Two stages: tanh soft clip then RMS energy limiter.

    Soft clip: `output = std::tanh(input * 1.5f) / std::tanh(1.5f)` -- unity gain for small signals, soft limiting for large.

    Energy limiter: Exponential RMS follower with stereo linking.
    - `rmsSquared += rmsAlpha * (input^2 - rmsSquared)` where rmsAlpha = 1 - exp(-2*pi / (0.05 * sr)) (~50ms window)
    - For stereo linking: provide `updateRms(float L, float R)` that computes rms from max(L*L, R*R)
    - Target gain: `(rms > threshold) ? threshold / rms : 1.0f` with threshold = 0.85f
    - Gain smoothing: attack alpha ~5ms, release alpha ~200ms
    - `process(float input)` applies `input * gain` after the soft clip stage

    The caller is responsible for calling `updateRms` once per sample (with both channel values) before calling `process` for each channel. This ensures both channels get the same gain.
