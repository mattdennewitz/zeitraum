<objective>
Create the FeedbackMatrix DSP class that routes 12 feedback sources (8 individual taps + 4 preset mixes) through independent gains to a single summed feedback bus.

Purpose: This is the core routing logic of the feedback matrix -- the defining feature of the plugin. Each of the 12 sources has an independent gain (0.0-1.0), and all are summed into a single feedback bus value per sample. The 4 preset mixes (Odd, Even, Rising, Falling) are fixed weighted sums of the 8 tap outputs.

Output: One header-only DSP class and one test file, registered in CMakeLists.txt.

```cpp
class FeedbackMatrix {
    static constexpr int numTaps = 8;
    static constexpr int numPresetMixes = 4;  // Odd, Even, Rising, Falling
    static constexpr int numSources = numTaps + numPresetMixes;  // 12

    // Fixed preset mix weights (normalized)
    static constexpr float oddWeights[8]     = {0.25f, 0.0f, 0.25f, 0.0f, 0.25f, 0.0f, 0.25f, 0.0f};
    static constexpr float evenWeights[8]    = {0.0f, 0.25f, 0.0f, 0.25f, 0.0f, 0.25f, 0.0f, 0.25f};
    static constexpr float risingWeights[8]  = {1/36.f, 2/36.f, 3/36.f, 4/36.f, 5/36.f, 6/36.f, 7/36.f, 8/36.f};
    static constexpr float fallingWeights[8] = {8/36.f, 7/36.f, 6/36.f, 5/36.f, 4/36.f, 3/36.f, 2/36.f, 1/36.f};

    void prepare(double sampleRate, int maxBlockSize);
    void reset();

    // Set feedback gain for tap source (index 0-7) or preset mix (index 8-11)
    void setSourceGain(int sourceIndex, float gain);  // 0.0 to 1.0

    // Compute feedback bus value from tap outputs for one sample
    // tapOutputs: array of 8 float values (current sample's tap outputs)
    // sampleIndex: index into pre-computed smoothed gain buffers
    float process(const float* tapOutputs, int sampleIndex);

    // Pre-compute smoothed gains for the block (call once before channel loop)
    void prepareSmoothGains(int numSamples);
};
```

    **FeedbackMatrix** (src/dsp/FeedbackMatrix.h):
    Header-only class. Uses OnePoleSmooth.h for gain smoothing.

    12 OnePoleSmooth instances for the 12 source gains (8 taps + 4 preset mixes). Smoothing time: 7ms (fast enough for responsive control, slow enough to avoid zipper noise).

    `prepare(double sampleRate, int maxBlockSize)`: Set sample rate on all 12 smoothers, set smoothing time to 7ms, allocate scratch buffers for pre-computed smoothed gains (12 x maxBlockSize floats).

    `setSourceGain(int sourceIndex, float gain)`: Set target on corresponding OnePoleSmooth. sourceIndex 0-7 = tap gains, 8 = Odd, 9 = Even, 10 = Rising, 11 = Falling.

    `prepareSmoothGains(int numSamples)`: Pre-compute smoothed gain values into scratch buffers for the block. This MUST be called once before the per-channel loop (same pattern as DelayEngine's smoother separation to avoid double-advancing smoothers across channels).

    `process(const float* tapOutputs, int sampleIndex)`:
    ```
    float bus = 0.0f;
    // Individual tap feedback
    for (int t = 0; t < 8; ++t)
        bus += tapOutputs[t] * smoothedGains[t][sampleIndex];
    // Preset mix feedback
    for (int m = 0; m < 4; ++m) {
        float mixSum = 0.0f;
        for (int t = 0; t < 8; ++t)
            mixSum += tapOutputs[t] * presetWeights[m][t];
        bus += mixSum * smoothedGains[8 + m][sampleIndex];
    }
    return bus;
    ```

    Preset weights as static constexpr arrays per the CONTEXT.md locked decisions:
    - Odd: taps 1,3,5,7 at 0.25 each (sum=1.0)
    - Even: taps 2,4,6,8 at 0.25 each (sum=1.0)
    - Rising: linear 1,2,3,4,5,6,7,8 normalized by /36 (sum=1.0)
    - Falling: linear 8,7,6,5,4,3,2,1 normalized by /36 (sum=1.0)

    `reset()`: Reset all 12 smoothers to 0.0f (all feedback off).
