   - "output" / "Output": OUTPUT_MIX

2. Add new parameters inside the Global group:
   - TEMPO_SYNC: AudioParameterBool, ParameterID{"TEMPO_SYNC", 1}, default false
   - NOTE_DIV: AudioParameterChoice, ParameterID{"NOTE_DIV", 1}, choices: {"1/4", "1/8", "1/8 dot", "1/8 trip", "1/16", "1/2"}, default 1 (1/8 note)

3. Keep ALL existing parameter IDs identical -- only the grouping container changes. All getRawParameterValue() calls continue to work unchanged.

4. Add valueToText formatting using AudioParameterFloatAttributes where the existing simple label strings are insufficient:
   - BASE_DELAY: already has "ms" label -- acceptable
   - MULTIPLIER: already has "x" label -- acceptable
   - MIX: already has "%" label -- acceptable
   - CHARACTER: already has "%" label -- acceptable
   - Tap positions: add stringFromValue showing percentage like "37.5%"
   - FB gains (FB_TAP1 etc.): already has "%" -- acceptable
   - FB_HP_FREQ, FB_LP_FREQ: already has "Hz" -- acceptable

5. In PluginProcessor.h, add cached parameter pointers:
   ```cpp
   std::atomic<float>* tempoSyncParam = nullptr;
   std::atomic<float>* noteDivParam = nullptr;
   ```

6. In PluginProcessor constructor, cache the new params:
   ```cpp
   tempoSyncParam = apvts.getRawParameterValue("TEMPO_SYNC");
   noteDivParam = apvts.getRawParameterValue("NOTE_DIV");
   ```

7. In processBlock, add tempo sync logic BEFORE the existing baseDelay load. Replace:
   ```cpp
   float baseDelay = baseDelayParam->load();
   ```
   With:
   ```cpp
   float baseDelay = baseDelayParam->load();

   if (tempoSyncParam->load() > 0.5f)
   {
       double bpm = 120.0; // fallback
       if (auto* playHead = getPlayHead())
       {
           if (auto pos = playHead->getPosition())
           {
               if (auto hostBpm = pos->getBpm())
                   bpm = *hostBpm;
           }
       }

       int divIndex = static_cast<int>(noteDivParam->load());
       static constexpr double divMultipliers[] = {
           1.0,        // 1/4
           0.5,        // 1/8
           0.75,       // dotted 1/8
           1.0 / 3.0,  // triplet 1/8
           0.25,       // 1/16
           2.0         // 1/2
       };

       double beatMs = 60000.0 / bpm;
       baseDelay = static_cast<float>(beatMs * divMultipliers[divIndex]);

       // Clamp to prevent exceeding delay line capacity
       // (allow values above 150ms since buffer handles up to 150*33=4950ms total)
       baseDelay = std::min(baseDelay, 150.0f);
   }
   ```

Note: Clamping baseDelay to 150.0f per research recommendation. The multiplier and tap positions scale on top, staying within delay line max.
