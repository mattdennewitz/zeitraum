  <behavior>
    OnePoleSmooth:
    - After calling setTargetValue(1.0) and running ~3x time constant samples, output is within 5% of target
    - reset(value) sets current immediately, getNextValue() returns that value
    - setSampleRate and setTimeMs recalculate alpha correctly
    - isSmoothing() returns true when current != target, false when converged

    CharacterProcessor:
    - With characterAmount=0.0, output equals input (clean passthrough)
    - With characterAmount=1.0, high frequencies (>8kHz) are attenuated by at least 3dB relative to low frequencies (~100Hz)
    - Noise floor is present when characterAmount > 0 and absent when characterAmount == 0
    - process() works per-channel independently (dual-mono ready)
  </behavior>
  <action>
    Write tests first (RED), then implement classes (GREEN).

    **OnePoleSmooth** (src/dsp/OnePoleSmooth.h):
    - Header-only, fully JUCE-free, no dependencies beyond cmath
    - Implements the one-pole exponential formula from CLAUDE.md: alpha = 1 - exp(-2*pi / (timeMs * 0.001 * sampleRate))
    - Methods: setTargetValue, reset, setSampleRate, setTimeMs, getNextValue, isSmoothing
    - Default: timeMs=10.0, sampleRate=44100.0
    - Threshold for isSmoothing: abs(target - current) > 1e-6f

    **CharacterProcessor** (src/dsp/CharacterProcessor.h):
    - Header-only, uses juce::dsp::FirstOrderTPTFilter for modulation-safe HF roll-off
    - Uses juce::Random for noise floor generation
    - Single method: float process(int channel, float sample, float characterAmount)
    - characterAmount 0.0-1.0 scales:
      - Lowpass cutoff from 20kHz (clean) down to ~4kHz (full BBD)
      - Noise level from 0.0 to ~0.0005 (-66dBFS, very subtle)
    - prepare(double sampleRate, int maxChannels) initializes the TPT filter
    - Filter is per-channel (dual-mono) so repeated calls on different channels are independent
    - The filter is cumulative: it sits in the delay feedback path, so each repeat darkens further

    **Tests:**
    - OnePoleSmoothTests.cpp: convergence test, reset test, isSmoothing test, time constant accuracy
    - CharacterProcessorTests.cpp: clean passthrough test, HF attenuation test (generate sine at 100Hz and 10kHz, compare RMS after processing at characterAmount=1.0), noise floor presence test
  </action>

  </verify>
