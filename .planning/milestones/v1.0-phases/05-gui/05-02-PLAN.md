**TapPositionBar.h — header-only custom component:**
- juce::Component subclass
- Constructor takes: juce::RangedAudioParameter& posParam, juce::AudioProcessorValueTreeState& apvts (for reading BASE_DELAY, MULTIPLIER, QUANTIZE for ms display and grid)
- Owns juce::ParameterAttachment for the position parameter
- Member: float currentValue (0-1 normalized position)
- paint():
  - Fill bar from bottom up to (currentValue * height) with teal accent color
  - If currentValue is zero or very low, still draw a minimum-height dim bar (always visible per user decision)
  - Draw horizontal line at bar top edge (the drag handle area)
  - Calculate and display ms value: read BASE_DELAY and MULTIPLIER from APVTS (message thread safe via getParameter()->getValue()), compute ms = currentValue * baseDelay * multiplier. Display as "XXms" text label on the bar.
  - If QUANTIZE is on: draw horizontal grid lines at each 10ms increment position within the bar range. Grid line y = (10ms_step / (baseDelay * multiplier)) * barHeight for each step.
- mouseDown(): Check if click is near the top edge of the bar (within ~8px). If so, start drag. Call attachment.beginGesture().
- mouseDrag(): Map mouse Y to 0-1 value (inverted — top of component = 1.0, bottom = 0.0). Clamp to 0-1. Call attachment.setValueAsPartOfGesture(newValue).
- mouseUp(): Call attachment.endGesture().
- mouseDoubleClick(): Show editable juce::Label overlay. Parse typed ms value back to normalized: newPos = typedMs / (baseDelay * multiplier). Clamp 0-1. Use attachment.setValueAsCompleteGesture(). Use callAsync to clean up label on editor hide (see research Pattern 4).
- Private setValue(float): called by attachment callback. Sets currentValue, calls repaint().

**TapLevelFader.h — header-only custom component:**
- juce::Component subclass
- Constructor takes: juce::RangedAudioParameter& levelParam
- Owns juce::ParameterAttachment for the level parameter
- Member: float currentValue (0-1 level)
- paint():
  - Draw vertical fader track (thin dark rectangle)
  - Draw fader fill from bottom to (currentValue * height) with teal accent
  - Display value as percentage text ("XX%") always visible
  - If value is 0, still show dim track (always visible per user decision)
- mouseDown(): attachment.beginGesture()
- mouseDrag(): Map mouse Y to 0-1 (inverted). attachment.setValueAsPartOfGesture().
- mouseUp(): attachment.endGesture()
- mouseDoubleClick(): Show editable label, parse percentage, convert to 0-1, setValueAsCompleteGesture().
- Private setValue(float): update currentValue, repaint().

Both components: use juce:: prefix everywhere. Use ScopedValueSetter<bool> ignoreCallbacks pattern to prevent feedback loops between attachment callback and gesture updates.
