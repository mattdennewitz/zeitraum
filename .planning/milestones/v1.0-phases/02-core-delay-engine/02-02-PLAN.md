    - Has OnePoleSmooth for position and level (smoothing time: 10ms for position, 5ms for level)

  <behavior>

    - Stereo operation: L and R channels process independently
    - With characterAmount=0.0, delay output matches a clean delay (no coloring)
  </behavior>
  <action>
    Write tests first (RED), then implement (GREEN).

    **DelayEngine** (src/dsp/DelayEngine.h):
    - Header-only, depends on juce::dsp::DelayLine, TapReader, CharacterProcessor, OnePoleSmooth
    - Owns: two juce::dsp::DelayLine<float, juce::dsp::DelayLineInterpolationTypes::Lagrange3rd> (one per channel)
    - Owns: 8 TapReader instances
    - Owns: CharacterProcessor instance
    - Owns: OnePoleSmooth for baseDelay, multiplier, character, mix parameters

    Methods:
    - `void prepare(double sampleRate, int maxBlockSize)`:
      - Calculate max delay: 150ms * 33 * sampleRate = max samples (e.g., 475200 at 96kHz)
      - Initialize both DelayLines with juce::dsp::ProcessSpec{sampleRate, maxBlockSize, 1}
      - Set max delay on both lines
      - Initialize all 8 TapReaders with default positions
      - Initialize CharacterProcessor
      - Reset all smoothers with new sample rate

    - `void process(juce::AudioBuffer<float>& buffer, float baseDelayMs, float multiplier, float characterAmount, bool quantize, const float* tapPositions, const float* tapLevels)`:
      - Update smoother targets from parameter values
      - Update TapReader positions and levels from arrays
      - Per channel, per sample:
        1. Get smoothed baseDelay, multiplier, character
        2. Apply character to input sample via CharacterProcessor
        3. Push processed sample into DelayLine
        4. Sum 8 taps: for each tap, get delaySamples from TapReader, popSample(0, delaySamples, false)
        5. Write wet sum to buffer (caller handles dry/wet mixing)

    - `void reset()`: Clear delay lines and reset all smoothers

    **Tests** (test/dsp/DelayEngineTests.cpp):
    - Impulse test: feed impulse, verify it appears at correct sample offset for tap at position 1.0
    - Multi-tap test: verify 8 impulse copies at different positions
    - Level test: tap at level 0.0 produces silence for that tap
    - Stereo test: process 2-channel buffer, verify both channels have output
    - The tests that need precise timing should use characterAmount=0.0 to avoid filter delay
