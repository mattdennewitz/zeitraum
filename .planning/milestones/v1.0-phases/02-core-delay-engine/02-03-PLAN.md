  <name>Task 1: Parameter layout and processor members</name>
  <files>src/PluginProcessor.h, src/PluginProcessor.cpp</files>
  <action>
    **PluginProcessor.h** -- Add private members:
    - `#include "dsp/DelayEngine.h"` (which transitively includes OnePoleSmooth, CharacterProcessor, TapReader)
    - `DelayEngine delayEngine;`
    - `juce::dsp::DryWetMixer<float> dryWetMixer;`
    - Cached parameter pointers (std::atomic<float>*):
      - `baseDelayParam`, `multiplierParam`, `mixParam`, `characterParam`, `quantizeParam`
      - `tapPosParams[8]`, `tapLevelParams[8]`
    - `double currentSampleRate = 44100.0;`

    **PluginProcessor.cpp** -- createParameterLayout():
    Implement the full parameter layout exactly as specified in 02-RESEARCH.md Code Examples section:
    - BASE_DELAY: 10-150ms, skew 0.5, default 80ms
    - MULTIPLIER: 1-33x, skew 0.4, default 1.0
    - MIX: 0-100%, default 50%
    - CHARACTER: 0-100%, default 25%
    - QUANTIZE: bool, default false
    - TAP1_POS through TAP8_POS: 0.0-1.0, defaults at i/8 equal spacing
    - TAP1_LEVEL through TAP8_LEVEL: 0.0-1.0, default 1.0
    - All use ParameterID{"NAME", 1} with version 1

    **Constructor** -- Cache all parameter pointers via getRawParameterValue:
    ```cpp
    baseDelayParam = apvts.getRawParameterValue("BASE_DELAY");
    multiplierParam = apvts.getRawParameterValue("MULTIPLIER");
    // ... etc for all parameters
    for (int i = 0; i < 8; ++i) {
        tapPosParams[i] = apvts.getRawParameterValue("TAP" + juce::String(i+1) + "_POS");
        tapLevelParams[i] = apvts.getRawParameterValue("TAP" + juce::String(i+1) + "_LEVEL");
    }
    ```

    **prepareToPlay** -- Initialize DSP:
    ```cpp
    currentSampleRate = sampleRate;
    delayEngine.prepare(sampleRate, samplesPerBlock);
    dryWetMixer.prepare({sampleRate, (uint32)samplesPerBlock, 2});
    dryWetMixer.setWetMixProportion(mixParam->load() / 100.0f);
    ```

    **processBlock** -- Full delay processing:
    1. ScopedNoDenormals (already exists)
    2. Load parameter values atomically
    3. Set DryWetMixer wet proportion from MIX (smoothed internally by DryWetMixer)
    4. Push dry samples into DryWetMixer
    5. Build tapPositions[8] and tapLevels[8] arrays from cached param pointers
    6. Call delayEngine.process(buffer, baseDelay, multiplier, character/100, quantize, tapPositions, tapLevels)
    7. Mix wet with dry via dryWetMixer.mixWetSamples
    8. Clear unused output channels (already exists)

    **getTailLengthSeconds** -- Return max delay time:
    ```cpp
    return 150.0 * 33.0 / 1000.0; // ~4.95 seconds
    ```

    **releaseResources** -- Reset delay engine:
    ```cpp
    delayEngine.reset();
    dryWetMixer.reset();
    ```
